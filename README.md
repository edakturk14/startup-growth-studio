# Startup growth studio website

A build handoff for **Ship & Tell Studio**, a working name for Eda Akturk’s new business.

This repository contains the agreed brief, a design reference, original images, and initial content data. The website implementation is intentionally left for Devin.

## Start here

Give Devin this instruction:

> Build the website in docs/DEVIN_PROMPT.md. Read that file in full, inspect docs/approved-mockup.png and docs/testimonial-reference.png, and use the original assets and content data already in this repository. The written brief overrides the mockup for Inter typography, the interactive work carousel, testimonials, and animations. Implement and verify the site, then open a pull request with desktop/mobile screenshots and a short motion recording.

## Included

- `docs/DEVIN_PROMPT.md`: complete implementation prompt, exact copy, carousel behaviors, animation requirements, and acceptance checks.
- `docs/approved-mockup.png`: studio website visual direction.
- `docs/testimonial-reference.png`: user-provided testimonial layout reference, not quote content.
- `docs/ASSET_SOURCES.md`: original asset URLs, provenance, and font inspection.
- `public/images/`: seven real source assets, including a founder photo.
- `content/projects.json`: six real projects with roles and links.
- `content/site-config.json`: initial brand/contact configuration.
- `content/testimonials.json`: empty until verified testimonials are supplied.

## Naming

The repository name is independent of the public company name and domain. Keep all displayed branding configurable. Ship & Tell Studio is provisional.

## Scope

A new standalone dark-mode business website. Eda is introduced as founder in About. The existing edatweets.com website and deployment are outside this build’s scope. Do not call prior founder work new studio client work.
